# Hallazgos de ingeniería y reglas propuestas

## Frontend

- **Hallazgo:** el encabezado muestra un periodo fijo, mientras que las fechas de ejemplo dependen del año y mes actuales. **Regla:** deriva el periodo visible de los datos o filtros activos; no lo fijes en la pantalla. Archivos: [frontend/src/App.tsx](frontend/src/App.tsx), [backend/app/routes.py](backend/app/routes.py).
- **Hallazgo:** el agrupamiento mensual convierte fechas ISO a `Date` y usa getters locales, lo que puede desplazar fechas al mes anterior según la zona horaria. **Regla:** procesa fechas ISO de forma independiente de la zona horaria local y prueba límites de mes. Archivos: [frontend/src/lib/financial-utils.ts](frontend/src/lib/financial-utils.ts), [frontend/src/lib/financial-utils.test.ts](frontend/src/lib/financial-utils.test.ts).
- **Hallazgo:** los tipos TypeScript describen movimientos, pero `response.json()` no valida la estructura en ejecución. **Regla:** valida la respuesta HTTP antes de calcular o renderizar, o cubre el contrato con una prueba de integración. Archivos: [frontend/src/App.tsx](frontend/src/App.tsx), [frontend/src/lib/financial-types.ts](frontend/src/lib/financial-types.ts).
- **Hallazgo:** los cálculos están separados de los componentes visuales, y los gráficos contemplan carga y ausencia de datos. **Regla:** mantén cálculos en utilidades probables, prueba sus fórmulas y conserva los estados de carga, error y datos vacíos. Archivos: [frontend/src/lib/financial-utils.ts](frontend/src/lib/financial-utils.ts), [frontend/src/lib/financial-utils.test.ts](frontend/src/lib/financial-utils.test.ts), [frontend/src/components/dashboard/income-outcome-chart.tsx](frontend/src/components/dashboard/income-outcome-chart.tsx), [frontend/src/components/dashboard/profit-percent-chart.tsx](frontend/src/components/dashboard/profit-percent-chart.tsx).

## Backend

- **Hallazgo:** las rutas declaran modelos de respuesta y tipos restringidos para varios parámetros. **Regla:** conserva esquemas explícitos y actualiza las pruebas cuando cambie una respuesta o consulta. Archivo: [backend/app/routes.py](backend/app/routes.py); pruebas: [backend/tests/test_routes.py](backend/tests/test_routes.py).
- **Hallazgo:** los filtros se comparten en una función, pero algunos filtros como `business_type` se aplican aparte y no están disponibles en todas las rutas. **Regla:** al añadir filtros, revisa endpoints relacionados y mantén diferencias intencionales documentadas y probadas. Archivos: [backend/app/routes.py](backend/app/routes.py), [backend/tests/test_routes.py](backend/tests/test_routes.py).
- **Hallazgo:** la generación de datos usa semilla para reproducibilidad mediante `random.seed()`, que modifica el generador aleatorio global. **Regla:** conserva resultados reproducibles en pruebas sin alterar el estado aleatorio compartido del proceso. Archivos: [backend/app/routes.py](backend/app/routes.py), [backend/tests/test_routes.py](backend/tests/test_routes.py).

## Integración

- **Hallazgo:** el modelo de movimiento se define en ambos lados; el backend usa `date` y el frontend recibe texto ISO en JSON. **Regla:** trata los nombres, tipos y valores permitidos como un contrato; cualquier cambio debe actualizar backend, frontend y pruebas conjuntamente. Archivos: [backend/app/routes.py](backend/app/routes.py), [frontend/src/lib/financial-types.ts](frontend/src/lib/financial-types.ts), [backend/tests/test_routes.py](backend/tests/test_routes.py), [frontend/src/lib/financial-utils.test.ts](frontend/src/lib/financial-utils.test.ts).
- **Hallazgo:** la pantalla principal consume `/api/metrics`; las rutas de resumen, comparación y alertas no están conectadas desde `App`. **Regla:** no des por integrada una función de API hasta verificar que la interfaz la consume; añade una prueba de integración cuando la pantalla dependa de nuevos endpoints. Archivos: [frontend/src/App.tsx](frontend/src/App.tsx), [backend/app/routes.py](backend/app/routes.py).
- **Hallazgo:** el código calcula beneficio y margen, pero no especifica por sí mismo la definición de negocio esperada; además, el periodo visual puede no coincidir con los datos. **Regla:** documenta las definiciones de métricas y periodo que el producto requiere, y alinea implementación y visualización con ellas. Archivos: [frontend/src/lib/financial-utils.ts](frontend/src/lib/financial-utils.ts), [frontend/src/App.tsx](frontend/src/App.tsx), [backend/app/routes.py](backend/app/routes.py).
